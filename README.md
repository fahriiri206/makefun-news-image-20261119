# Sum up 19 November's world news in one image

This is the entry for make.fun's "Sum up 19 November's world news in one image" competition, covering the world news of Thursday 19 November 2026. The finished page is a newspaper-style front page named "The World Today", whose masthead carries Thursday 19 November 2026 in large type. It carries three illustrated features (the first Trump–Xi–Putin trilateral at APEC in Shenzhen, GTA VI's launch, and Anthropic's first day on Nasdaq, which closed at $97.17) and ten illustrated story cards, including the ICJ genocide ruling on Myanmar, Cyclone Akvan in Odisha, the Van Gogh auction record, UniCredit and Commerzbank, Colombia's national strike, Cyril Ramaphosa's AI investment pitch, the Archimedes engine, Juan Mata's retirement and the Save the Children count of children in conflict zones. It also has a world map with keyed event markers, four figure boxes, a date-check box and 33 numbered briefs across Europe, the Middle East, Asia-Pacific, the Americas, Africa, Oceania and the world. The page carries 46 stories in total, and the day's stories are named in the picture itself.

## Run it

```sh
python3 main.py
```

This writes the validated image to `/output/entry.png` (or to `MAKEFUN_OUTPUT_DIR` when that variable is set). The program uses the Python standard library only, makes no network calls, and is deterministic: the same committed `entry.png` always produces the same bytes.
